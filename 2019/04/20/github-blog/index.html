二、安裝

1.依賴

  • Hexo
    • nodejs
  • GitHub Pages(github.io)

2.安裝環境

  • 下載並安裝 Git

  • 安裝 Node.js

    參考：Node.js 安裝配置

3.初始化工作目錄

  • 在D碟建立工作目錄workspace
  • 工作目錄上按右鍵，打開 Git Bash

4.安裝Hexo

Git bash中，透過 npm 即可完成 Hexo 的安裝。

5.初始化Hexo

一旦 Hexo 完成後，請執行下列指令，Hexo 會在指定資料夾中建立所有您需要的檔案。

6.設定Hexo

網站 配置 檔案，您可以在此配置大部分的設定。

重要參數說明：

  • url: 你的 GitHub Pages 網址（格式：https://<username>.github.io）
  • post_asset_folder: 設為 true 可讓每篇文章擁有獨立的資源資料夾，方便管理圖片
  • deploy.repo: 你的 GitHub Pages repository URL

部署前準備：

  1. 在 GitHub 建立名為 <username>.github.io 的 public repository
  2. 設定 SSH key，參考：Git 安裝、帳號安全設定
  3. 安裝部署插件：npm install hexo-deployer-git --save

常見部署問題：

  • SSH key 權限錯誤：確認 SSH key 已加入 GitHub（ssh -T git@github.com 測試連線）
  • deploy 失敗：檢查 _config.yml 中的 deploy.repo 是否正確
  • 主題顯示異常：執行 hexo clean 清除快取後重新產生
